什么是 Lance？

Lance 是一种现代、开源的面向多模态 AI 的湖仓格式。它包含文件格式、表格式和目录规范， 允许你在对象存储之上构建完整的开放湖仓，为你的 AI 工作流提供动力。 Lance 为湖仓带来了高性能向量搜索、全文搜索、随机访问和特征工程能力， 同时你仍然可以享受现有湖仓的所有优势，如 SQL 分析、ACID 事务、时间旅行， 以及与开放引擎（Apache Spark、Ray、PyTorch、Trino、DuckDB 等） 和开放目录（Apache Polaris、Unity Catalog、Apache Gravitino、Hive Metastore 等）的集成。

阅读我们在 VLDB 2025 上发表的 研究论文 了解更多 Lance 的技术细节。

表达力强的混合搜索

Lance 支持强大的混合搜索，将向量相似性搜索、全文搜索和 SQL 分析组合在同一数据集上。 所有查询类型都通过相应的二级索引进行加速，这是 Lance 规范的一部分。

在嵌入向量上运行语义搜索，在关键词上进行 BM25 搜索，并应用复杂的 SQL 谓词 —— 所有这些都使用单个表和统一的接口。

极速随机访问

Lance 的随机访问速度比 Parquet 或 Iceberg 快 100 倍。 与传统格式不同，Lance 即使在整个数据集中随机访问分散的行时也能保持高性能。

凭借高度优化的文件格式，加上表级别高效的行寻址和二级索引， 你可以跨多个文件即时访问单条记录，非常适合实时 ML 服务、随机采样和交互式应用。

原生多模态数据支持

在单一统一格式中存储图像、视频、音频、文本和嵌入向量，与传统表格数据并存。 Lance 的 blob 编码高效处理大型二进制对象并支持延迟加载， 同时优化的向量存储加速相似性搜索。

非常适合 AI/ML 工作负载，你可以将原始数据、ML 特征、生成的标题和嵌入向量 全部存储在一起，用于多模态检索和生成式 AI 工作流。

数据演进 > Schema 演进

大多数开放表格式中的 Schema 演进仅限于元数据变更，速度很快。 但当尝试回填现有行中的列值时，通常需要完整的表重写。 Lance 支持数据演进（带回填的高效 Schema 演进），非常适合 ML 特征工程、嵌入向量和媒体内容管理。

添加带数据的新列就像向 Lance 表写入新的 Lance 文件一样简单 —— 无需重写整个数据集。

丰富的生态系统集成

作为开放格式，Lance 与 Python 数据生态系统和现代数据平台无缝集成。 使用你喜爱的工具，包括 Pandas、Polars、Ray 和 PyTorch 进行数据处理和机器学习。

连接领先的查询引擎，如 Apache DataFusion、DuckDB、Apache Spark、Trino 和 Apache Flink/Fluss， 在你的 Lance 数据集上运行 SQL 分析和分布式处理。
