# 标签列表索引（Label List Index）

标签列表索引针对每行包含多个标签或标记的列进行了优化。
它使用底层的位图索引提供高效的集合查询。

## 索引详情

```protobuf
%%% proto.message.LabelListIndexDetails %%%
```

## 存储布局

标签列表索引在内部使用位图索引，数据存储在：

1. `bitmap_page_lookup.lance` - 将唯一标签映射到行 ID 的位图索引

### 文件 Schema

| 列        | 类型       | 可空 | 描述                                                       |
|-----------|------------|------|------------------------------------------------------------|
| `keys`    | {DataType} | true | 索引列中的唯一标签值                                        |
| `bitmaps` | Binary     | true | 序列化的 RowAddrTreeMap，包含该标签出现的行地址              |

## 加速查询

标签列表索引为以下查询类型提供精确结果：

| 查询类型                             | 描述                        | 操作                                 | 结果类型 |
|-------------------------------------|-----------------------------|--------------------------------------|---------|
| **array_has / array_contains**      | 数组包含指定值               | 单个标签的位图查找                    | Exact   |
| **array_has_all**                   | 数组包含所有指定值            | 交集所有指定标签的位图                | Exact   |
| **array_has_any**                   | 数组包含任一指定值            | 合并所有指定标签的位图                | Exact   |
