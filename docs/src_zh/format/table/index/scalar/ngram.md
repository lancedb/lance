# N-gram 索引

N-gram 索引将文本分解为重叠的序列（三元组），用于高效的子串匹配。
它通过对文本中所有 3 字符序列进行索引（经过 ASCII 折叠和小写转换后），提供快速的文本搜索。

## 索引详情

```protobuf
%%% proto.message.NGramIndexDetails %%%
```

## 存储布局

N-gram 索引将分词后的文本作为三元组及其倒排列表存储：

1. `ngram_postings.lance` - 三元组词元及其倒排列表

### 文件 Schema

| 列             | 类型   | 可空  | 描述                         |
|----------------|--------|-------|------------------------------|
| `tokens`       | UInt32 | true  | 哈希后的三元组词元            |
| `posting_list` | Binary | false | 包含该词元的行 ID 压缩位图    |

## 加速查询

N-gram 索引为以下查询类型提供非精确结果：

| 查询类型     | 描述           | 操作                                     | 结果类型 |
|-------------|----------------|------------------------------------------|---------|
| **contains** | 文本中的子串搜索 | 找到查询中的所有三元组，交集倒排列表        | AtMost  |
