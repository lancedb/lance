# 版本管理（Versioning）

Lance 文件格式对整体文件格式和编码策略使用单一版本号。当文件格式本身发生修改时，主版本号（Major Number）会变更；当仅编码策略发生修改时，次版本号（Minor Number）会变更。较新的版本通常具有更好的性能和压缩率，但可能无法被旧版本的 Lance 读取。

此外，`next` 别名指向一个不稳定的格式版本，不应用于生产环境。不稳定编码可能会发生破坏性变更（Breaking Changes），这意味着使用这些编码写入的文件将无法被任何更新版本的 Lance 读取。`next` 版本仅应用于实验和即将推出功能的基准测试。

`stable` 和 `next` 别名由你使用的特定 Lance 发行版决定。在格式推出期间（例如 2.2），建议使用显式版本固定以确保跨环境的确定性行为。

支持以下版本值：

| 版本             | 最低 Lance 版本       | 最高 Lance 版本       | 描述 |
| --------------- | --------------------- | --------------------- | ---- |
| 0.1             | 任意                  | 0.34（仅写入）         | 这是 Lance 的初始格式，已不再可写。 |
| 2.0             | 0.16.0                | 任意                  | Lance 文件格式的重构，移除了行组（Row Groups），并为列表（List）、固定大小列表（Fixed Size List）和基本类型（Primitives）引入了空值（Null）支持。 |
| 2.1             | 0.38.1                | 任意                  | 增强了整数和字符串压缩，增加了结构体字段（Struct Fields）的空值支持，并改进了嵌套字段的随机访问性能。 |
| 2.2（不稳定）    | 无                    | 任意                  | 添加了对更新的嵌套类型/编码功能的支持（包括 Map 支持）以及 2.2 时代的存储特性。 |
| legacy          | N/A                   | N/A                   | 0.1 的别名 |
| stable          | N/A                   | N/A                   | 你当前运行的 Lance 发行版中最新稳定版本的别名。 |
| next            | N/A                   | N/A                   | 你当前运行的 Lance 发行版中最新不稳定版本的别名。 |
