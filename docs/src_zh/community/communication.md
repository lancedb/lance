# 沟通

## Discord

Discord 用于日常讨论、社区支持和实时协作。
使用 [此邀请链接](https://discord.gg/lance) 加入并打个招呼！

## GitHub Discussions

GitHub Discussions 用于开发讨论、设计提案、公开投票和公告。

## GitHub Issues

GitHub Issues 用于项目问题跟踪和路线图发布。

## GitHub Pull Requests

GitHub Pull Requests 用于项目代码审查和代码贡献。

## 邮件列表

Lance 使用两个邮件列表：

- [dev@lance.org](https://groups.google.com/a/lance.org/g/dev)：GitHub Discussions 讨论的存档（公开）
- [private@lance.org](https://groups.google.com/a/lance.org/g/private)：私有讨论、安全和骚扰问题报告、投票（私有，仅 PMC 成员可见）

## 社区同步会议

我们每隔一周的周四上午 9 点（太平洋时间）举行 Lance 社区同步会议。欢迎所有人参加！

- 订阅 [Lance Format 邮件列表](https://groups.google.com/a/lance.org/g/dev) 以接收会议邀请
- 欢迎在 [会议记录](https://docs.google.com/document/d/1cP058pJLVjj39DGaFV5yHI6qyWBwp1B2YKyIwXzYlAI/edit?tab=t.0) 中建议讨论主题
- 过往录像可在 [此处](https://www.youtube.com/playlist?list=PLQysAafL04jUgOj7j6mCE5fcZEBB9Amu9) 找到

如果你无法看到日历邀请，请通过邮件列表或 [Lance Discord](https://discord.gg/lance) 联系我们。
