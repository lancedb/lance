# Lance 社区投票流程

Lance 使用基于共识的投票流程进行决策。

## 表达投票

投票以以下方式表达：

- **+1**：赞成
- **0**：弃权
- **-1**：反对

投票时，建议投票人表明其投票是否具有约束力（例如 `+1 (non-binding)`、`-1 (binding)`），
以便于统计约束性投票。

除了投票本身，投票人还可以在评论中表达其理由。
**-1** 投票必须附带理由，以便进行有意义的讨论。
任何未附带理由的 **-1** 投票将被视为无效。

对于在 GitHub Discussions 上进行的投票，
每次投票应作为独立评论发布，而不是作为某个评论的回复。
这确保了人们可以在该特定评论下讨论投票结果
（例如，讨论 **-1** 否决权或解决关切）。

## 约束性投票（Binding Votes）

每项决策仅计算约束性投票人的投票，
但社区中的其他人也被鼓励投出非约束性投票。
约束性投票人在投票过程中应考虑来自非约束性投票人的任何关切。

## 否决权（Vetoes）

**-1** 约束性投票对所有决策类型均视为否决。否决权：

- 在关切得到解决之前暂停提案
- 不能被推翻
- 触发共识收集以解决关切
