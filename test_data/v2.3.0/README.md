# Lance 2.3 sparse reader fixture

`sparse_reader.lance` and `empty_sparse_reader.lance` are Lance file-version 2.3 fixtures
generated by the checked-in isolated tool linked to the final sparse structural layout prototype at
commit `1aca0a6d4fbb1010adb3b8fc2d0b6951a11e736b` (`lance-file` 9.0.0-beta.12).
Their matching `.arrow` files contain the same record batches in Arrow IPC form and are the
expected results used by reader compatibility tests. The empty fixture's page descriptor is
assembled by the isolated test generator because the production prototype short-circuited
zero-visible pages before explicit sparse selection.

The fixture covers nullable primitive and struct values, list, large-list, map,
fixed-size-list, null and empty lists, both validity polarities, every semantic position
and count representation, deeply nested layers, multiple value chunks, and a list column
with no leaf values.

Regenerate it with:

```shell
python test_data/v2.3.0/datagen.py
```

The generator is isolated under `test_data`; no production sparse writer is included in
the reader change.
